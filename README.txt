DEPLOY TO CLOUDFLARE PAGES (FREE STATIC HOSTING)
1. Sign in to Cloudflare and open Workers & Pages.
2. Choose Create application / Pages, then Direct Upload (wording may vary).
3. Upload this ZIP or the extracted folder contents. Ensure index.html is at the root of the uploaded site, not inside an extra nested folder.
4. Deploy, then open the provided pages.dev URL and test on a phone.
5. Test every WhatsApp button and submit a sample booking request. The form opens WhatsApp; it does not itself confirm or store reservations.

No build command is needed for this plain HTML/CSS/JavaScript site.
